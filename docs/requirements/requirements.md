## WIP

FR-001  The system shall allow the user to create a planning problem.

FR-002  The system shall allow resources to be defined.

FR-003  The system shall allow activities to be defined.

FR-004  The system shall allow time slots to be defined.

FR-005  The system shall support hard and soft constraints.

FR-006  The system shall generate schedules using a genetic algorithm.

FR-007  The system shall display the generated schedule graphically.

NFR-001  The application shall provide a graphical web interface.

NFR-002  The genetic engine shall be independent of the planning domain.

NFR-003  The application shall be executable on different operating systems.

NFR-004  The UI shall not require knowledge of genetic algorithms.
